# Adding Your Design Project Images

To add your design project images to the portfolio, follow these steps:

## Image Files Needed

Save these images to the `public` folder:

1. **stephen-classic.png** - Stephen Classic logo design
2. **corestone.png** - Corestone Construction logo
3. **lamsy-beauty.png** - Lamsy Beauty Empire portfolio design
4. **acf-march.png** - ACF March campaign design

## Steps to Add Images

1. Export your design images from CorelDraw as PNG files (recommended format)
2. Place them in: `portfolio/public/` folder
3. Rename them to match the filenames above
4. Refresh your browser - images will automatically appear!

## Recommended Image Specifications

- **Size**: 800x600px or larger
- **Format**: PNG (supports transparency) or JPG
- **File Size**: Keep under 500KB for best performance
