# Portfolio Website

A modern, responsive portfolio website built with Next.js, React, TypeScript, and Tailwind CSS.

## Features

- 📱 Fully responsive design
- ⚡ Fast and optimized with Next.js
- 🎨 Beautiful UI with Tailwind CSS
- 📧 Contact form with email support
- 🚀 Ready to deploy

## Sections

- **Hero** - Introduction and call-to-action
- **Projects** - Showcase your best work
- **Skills** - Display technical skills
- **Contact** - Get in touch form

## Getting Started

### Prerequisites

- Node.js 18+ and npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building

```bash
npm run build
npm start
```

## Customization

1. Update `Hero` component with your name and bio
2. Add your projects to the `Projects` component
3. Update skills in the `Skills` component
4. Configure contact information
5. Replace links with your social media profiles
